# Что перенесено в веб-версию

## Из H2HClientWpf

- список, добавление, редактирование и удаление мерчантов;
- Dev/Prod режимы и отдельные API-ключи;
- создание H2H payment и H2H debit сессий;
- отмена сессии;
- открытие диспута с 1–5 фотографиями JPG/PNG/WEBP;
- авторизация в платформе, баланс и заявка на вывод;
- тестовый USDT TRC-20 депозит в Nile;
- история операций;
- HMAC SHA-256, timestamp и idempotency key.

## Что полезного взято из WebsiteForTests/main.py

- сайт работает как серверный прокси: секреты и HMAC не попадают в JavaScript браузера;
- показываются время ответа, request JSON и response JSON;
- callback URL формируется автоматически от публичного адреса сайта;
- webhook принимается обычным ASP.NET endpoint без локального HttpListener и порта;
- операции собраны в одном browser dashboard;
- результат сохраняется после POST через redirect, поэтому обновление страницы не повторяет платёжный запрос.

## Что намеренно не переносилось один в один

- API Key и Secret не сохраняются в `localStorage` и не отдаются клиентскому JavaScript;
- отключение TLS-проверки разрешено только для `localhost`/`127.0.0.1`;
- тестовые ключи и пароли из XAML не перенесены;
- `/payment-sessions/test` из текущего Flask-файла не добавлен: там подписывается и отправляется только число `amount`, а не исходный DTO. Перед переносом этот контракт лучше подтвердить у API;
- локальный webhook-сервер WPF заменён постоянным `/api/webhooks/payment`;
- JWT платформы хранится только в server-side сессии браузера, а не в `settings.json`.
